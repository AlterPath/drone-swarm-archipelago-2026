# Рой квадрокоптеров: задачи «Архипелага 2026»

[English version](README.en.md)

Код для трёх задач интенсива «Архипелаг 2026» (июнь 2026): Змейка, Лабиринт и Склад. Задачи решались командой, весь код в репозитории написан мной.

## Задачи

### Змейка (`snake/`)

Четыре дрона летят колонной змейкой между конусами.

- **Ведущий** (`drone_1.py`) проходит маршрут слалома по опорным точкам, сгущённым с шагом 0,2 м. Фазы полёта (`stage`, `go`, `land`) он рассылает в общий топик `/swarm/cmd`.
- **Ведомые** (`drone_2.py` … `drone_4.py`) подписаны на телеметрию предшественника. Они хранят «хлебные крошки» его пути и держатся на 0,6 м позади вдоль траектории, а не по прямой. Поэтому колонна повторяет изгибы маршрута.

### Лабиринт (`maze/maze.py`)

Дрон исследует лабиринт по лидару.

- Облако точек делится на четыре сектора по ±30° вокруг направлений движения, по ним видно, куда свободно.
- Обход клеток 0,9 × 0,9 м идёт в глубину (DFS): множество посещённых клеток и стек для возврата.
- Во время шага дрон останавливается, если впереди меньше 0,3 м.

### Склад (`warehouse/main.py`)

Рой из четырёх дронов облетает склад.

- Общий маршрут собран из опорных точек: вход, проход вдоль стены, полосы между стеллажами, возврат.
- Дроны идут колонной со сдвигом по маршруту в четыре точки.
- В точке у контейнера выполняется считывание датчиком.
- В конце дроны выходят наружу и садятся в линию.

## Платформа

Код запускается на симуляторе и дронах организаторов. Классы `Drone` и `Swarm`, `ros_bridge` (модуль `core`) и датчики (`sverk_interfaces`) предоставляет платформа интенсива, в репозиторий они не входят.

## Стек

Python, ROS (через мост платформы), лидар, групповое управление.
